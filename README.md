# IBM Bob Intelligent Work Copilot

## 🚀 Overview
AI-powered enterprise engineering copilot built for the IBM Bob Hackathon.

## Features
- Repo Brain (system understanding)
- Incident Debugging Autopilot
- Workflow Automation Builder

## Powered by IBM Bob
This project demonstrates meaningful IBM Bob usage through:
- Prompt orchestration
- Context-aware reasoning
- Incident analysis
- Workflow generation

## Tech Stack
- Python
- FastAPI
- Streamlit
- IBM Bob

## Run Locally

```bash
pip install -r requirements.txt
streamlit run frontend/streamlit_app.py
```
